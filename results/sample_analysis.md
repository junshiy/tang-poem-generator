# "最好的一段"与"最差的一段"分析（基础任务要求）

数据口径：`generate_table.py` 在同一模型（我的唐诗.h5，训练 50 轮，最低 loss 4.74）、
同一参数（temperature=1.5，总长 20 字）下生成 8 个开头 × 2 段共 16 条结果，
从中人工挑选最好与最差各一段。
（注：早期运行曾出现 <UNK> 字符，已在采样阶段屏蔽 0 号 <UNK> 修复，
见文末"问题修复记录"。）

## 一、最好的一段

> **开头「月」第 1 段**：月明楚寺峻，夜卧五峰无。路疏故情生，云应开阁暮。

判断理由：

1. **连贯性**："月明""夜卧""云暮"从月夜写到暮色回望，句内搭配基本通顺，
   "夜卧五峰无"有山寺夜宿的画面感。
2. **主题一致性**：四句都围绕"山寺月夜"展开——月、寺、峰、路、云、阁
   意象统一，是一幅完整的夜景，没有明显跑题。
3. **重复度低**：段内无重复用字，与其他 15 条也没有雷同句式。
4. **格式正确**：完整的"五言，五言。五言，五言。"结构。

## 二、最差的一段

> **开头「春」第 2 段**：春集肯暂鸣，名之西鼙筑。愁幂光小妆，潜向郊原衢。

判断理由：

1. **连贯性差**："名之西鼙筑""愁幂光小妆"词与词之间没有可理解的搭配关系，
   逐字读不成句。
2. **主题不统一**：开头是"春"与鸟鸣，后面出现"西""筑""妆""衢"等
   不相关意象，整段没有统一画面。
3. **用字生僻**："鼙""幂""衢"虽在词表内，但都是低频字，说明模型对低频字
   的接续预测不可靠——这正是 temperature 偏高时采样到低概率字的表现。

## 三、原因分析与改进思路

| 问题 | 原因 | 改进思路 |
|---|---|---|
| 语句不通顺 | 只训练了 50 轮（课程原代码为 500 轮），loss 从 6.03 降到 4.74 后仍在下降 | 延长训练轮数；或增大 LSTM 隐藏单元 |
| 用字生僻、意象跳跃 | temperature=1.5 采样随机性大，容易采到低概率字 | 降低 temperature 做对比实验（已做，见 results/温度对比分析.md：0.5 时通顺度明显提升） |
| 曾出现 <UNK> | 低频字被过滤进 <UNK> 后仍可能被采样 | 已修复：采样时屏蔽 0 号 <UNK> 并重新归一化（见下） |

## 四、问题修复记录

基础任务阶段发现部分生成结果含 `<UNK>`。原因：预处理把词频 < 5 的字统一编码为
`<UNK>`（编号 0），但采样时它仍在候选中。修复：在 `utils.py` 的采样函数
`random_max` 中把 0 号概率置 0 并重新归一化，使 `<UNK>` 永远不会被选中。
修复后重新生成全部结果表（16 + 18 + 5 条），均未再出现 `<UNK>`。
该模型无需重新训练——问题出在生成阶段的采样，与训练无关。

## 五、结论

基础任务下模型已经学会了五言诗的"外形"（格式 100% 正确、常见字搭配大多合理、
能形成统一意象的段落），但对低频字和长距离语义连贯的把握仍不足，
整体处于"能看出像诗、但经不起逐字推敲"的水平——这与 50 轮的训练量和
字符级 LSTM 的能力是匹配的。
